# FakeStoreVueJS

Conception à l’aide de Vue.Js d'un site web de vente en ligne.

## Fonctionaliter

La personne utilisant votre site pourra :

- Afficher les articles
- Trier les articles par catégorie
- Voir les détails d’un élément choisi
- Se créer un compte/ s’authentifier

Le site communique avec l’API « [FakeStoreAPI](https://fakestoreapi.com/) »
Le site gere les comptes avec [Firebase](https://firebase.google.com/?utm_source=google&utm_medium=cpc&utm_campaign=Cloud-SS-DR-Firebase-FY26-global-gsem-1713590&utm_content=text-ad&utm_term=KW_firebase&gclsrc=aw.ds&gad_source=1&gad_campaignid=23417478209&gbraid=0AAAAADpUDOgZqHLAf2Q2MsVaA9_A_xhF_&gclid=Cj0KCQiA7fbLBhDJARIsAOAqhschhRQW2me3KiZetbjcoqXF-1w42HdoAd-IKFQTtS-Hxc2OmRyaR2MaAg8tEALw_wcB)
